# 05 Retrospective

## 难点与收获

最关键的风险是让脚本“看起来完整”却没有素材/事实来源。因此把来源 ID、规则检查和时长估算放进显式 Trace，并让无结果/失败路径终止而不是编造内容。

## 实际范围

完成 CLI、合成素材工具、受限 Agent 循环、SQLite 结果持久化、自动化测试、四组 fallback 证据和一组脱敏的真实在线 LLM 证据。未完成真实素材检索、人工品牌审核、视频渲染和发布接入。

## 实际投入

本次核心实现、测试、文档与证据生成在单次笔试开发时段内完成；未将离线设计讨论或等待时间计入实现时长。

## 风险与下一步

下一步应接入受权限约束的真实素材检索和结构化品牌规则服务，并扩展不同工具结果下的真实模型评估。真实在线 LLM 的脱敏证据已经保存在 `examples/05-live-llm-decision.json`。实际耗时以 Git 提交和终端验证时间为准，不在文档中虚构。
