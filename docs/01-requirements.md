# 01 Requirements

## 用户与目标

内容创作者需要快速生成一份可以人工继续编辑的短视频脚本。用户输入主题、受众、目标时长、风格、产品素材和品牌规则；Agent 交付标题、分镜、旁白/字幕、预计总时长、素材来源 ID、风险和任务状态。

## 成功标准

1. P01 仅有“支持字幕”事实，目标 30 秒时首稿 38 秒，Agent 必须依据时长工具结果压缩后复估，不能直接声称完成。
2. 无素材结果时，Agent 先安全改写检索，再请求补充信息；不能虚构素材来源或效果数据。
3. 品牌风险、工具失败和执行步数上限分别返回 `blocked`、`failed`、`incomplete`，不伪装成功。
4. 每次运行的 Trace 记录节点、动作、脱敏参数、结果摘要、下一动作和简短理由。
5. CLI、测试和证据可从本题目录复现。

## 范围与非目标

本题使用 Python CLI、SQLite、Pydantic 与受约束的 Agent 循环。素材库是安全合成数据；不包含真实素材平台、视频渲染、语音、HTTP API、账号权限或发布。

## 已知约束

无 LLM 配置时使用显式 fallback。fallback 只验证受限流程和业务边界，不作为在线模型能力证据。
